## 1. v0.2 的界面决策：一个入口，两个状态层

v0.1 用两个主屏图标分开"手持管理"与"挂墙展示"。本轮按你的要求合成一个：**壁挂态是宿主，管理功能以覆盖层的形式长在它身上。**

这个决定是对的，理由比"少一个图标"更实际——挂墙屏原本就是全家视线交汇点，把"改一下"放在它上面，等于给这块屏加了反馈回路：谁路过发现日程错了，抬手就改掉了。分成两个入口时，壁挂屏会逐渐退化成只读海报，而日程一旦没人负责纠正，两周后就没人信它了。

代价是**误触风险**，所以覆盖层的进入方式、手势白名单、自动回落都必须在设计期定死（§2、§3.8）。

### 1.1 两种阅读距离仍然不同

| | 壁挂态（宿主） | 管理覆盖层 |
|---|---|---|
| 距离 | 2–3.5m | 走近 40–60cm |
| 密度 | 极低，今天最多 6 条 | 高，月历 + 列表 |
| 主题 | 深色 | 深色（不再切浅色，见 §1.2） |
| 触控目标 | ≥ 64pt | ≥ 48pt |
| 字号下限 | 22pt（3 米可读） | 15pt |
| 基准视口 | 1180×820 pt（Air 3 横屏逻辑分辨率） | 同 |

### 1.2 主题：默认深色，但风格可切换（v0.3 修订）

v0.2 曾定"全 App 一套深色"。本轮按你的要求改成**主题可选**——理由站得住：挂墙屏在厨房强光下深色看不清、在卧室夜里浅色太亮，同一套配色不可能两头都好。

四套主题（`04` 无，规范即本文 §4.1）：`ink 墨蓝`（夜间友好）、`night 夜灰`（纯黑底，卧室 / OLED）、`paper 纸白`（白天、厨房强光、老人看）、**`wood 暖木`（默认，纸质暖色，客厅装饰感强）**。

规则只有三条：**一套结构令牌 + 四份色值表**（禁止任何组件写死颜色，只准引用 `var(--c-*)`）；成员色在每套主题里各自有一档（浅色主题用深档、深色主题用亮档），**徽章始终是"色块 + 首字"双编码**；主题值存在服务端 `meta.theme`，全家共享一个风格——这块屏是公共物件，不该每台设备各切各的。

管理界面在深色下仍靠层级（底 / 卡 / 线 / 悬停）拉开对比，浅色主题下改用边框 + 极浅阴影，不靠"背景变灰"承载信息层级。

## 2. 模式状态机

```
                    ┌──────────────── 静止 60 秒（无任何触摸）────────────────┐
                    │                                                      │
  ┌───────── 触摸展开 ──────┐                                              ▼
┌─┴────────┐   点日程卡   ┌─┴─────────┐   点"编辑"  ┌──────────┐      ┌──────────┐
│  KIOSK   │─────────────▶│  DETAIL   │───────────▶│  EDITOR  │─────▶│ SYNCING  │
│ 壁挂轮播 │◀─────────────│ 详情覆盖层 │◀───────────│ 编辑抽屉 │      │ 写请求中  │
└─┬────────┘   关闭/超时   └───────────┘  保存/取消  └──────────┘      └────┬─────┘
  │  点齿轮(淡出显示)                                                      │ 200/409/失败
  ▼                                                                        ▼
┌──────────────┐  点日程   ┌─────────┐                     成功→回上层 / 冲突→ CONFLICT
│ SHEET 全屏管理 │─────────▶│  DETAIL │                     失败→ 入 pending，标"待同步"
│（占满视口，非弹窗）│◀────────└─────────┘
└──────────────┘
   其它子面板：RECUR_ASK(重复三选一) · 顶栏 tab：日历/待办/倒数日/成员/外观与主题/提醒/壁挂/备份/关于

不变量：
  1. DETAIL / RECUR_ASK / CONFLICT 是遮罩上的小卡；**SHEET 不是弹窗，是整屏页面**（v0.3 改）
  2. 除 KIOSK 外任何层都暂停轮播；回到 KIOSK 才恢复计时
  3. 只有非 EDITOR 层受 60 秒自动回落影响（正在打字时绝不自动关）
  4. Esc / 点遮罩空白 = 只收起最上层浮层；浮层都不在时按 Esc 无动作。退出管理页必须点右上角「✕ 回到壁挂」或等 60 秒自动回落
```

## 3. 画面规格

### 3.1 KIOSK 壁挂态（默认，99% 时间停在这）

分栏 **70/30**。v0.5 起壁挂端**只剩顶栏 + 主区 + 右栏三块**：底部那一横条（页码圆点、页名、版本戳、"收起浮层"按钮）整体删除，信息并入标题行；顶部"原型演示"胶囊条也移出壁挂端，测试入口全部收进管理页"关于"（§3.12）。

- **顶栏**（120pt）：`10月6日`（64pt）+ `星期二`（28pt）+ 右侧同步状态点与时钟 `14:32:07`（72pt 等宽数字）。
- **主区 70%（轮播四页）**，标题行 `本周 · 周视图 · 2/4 页` 同时承担页名与页码，不再另设底栏：
  - `今天`：最多 6 张大卡（高 88pt、标题 34pt、时间块 40pt 等宽、成员色条 8pt + 圆形徽章）。📌 置顶永远第一并带图钉。
  - `本周`：7 列壁挂版周视图，列头"周二 6"（今天列主色底强调），每列最多 4 条 22pt 大字 + `+N`。点某列 → 跳到该日的今天态，这是周页唯一的导航手势。
  - `本月`：7×6 月网格壁挂版，**字号回到第一版档（日号 `--t-item` 2.2vmin、条目 1.7vmin），每格显示 2 条 + "+N"**。v0.6 为放大字号砍成 1 条是错的判断：整月概览的首要价值是"这天有没有事、是谁的"，砍掉第二条等于把信息换成看不太清的大字。点格 → 跳到该日。
  - `待办`：未完成清单，每页 6 张大卡（高 11vmin、标题 3.6vmin）配 **6.4vmin 大圆圈**，走近抬手即打勾；第 7 条起显示"还有 N 条未完成"。它从右栏小盒升格为整页的理由很直接：**右栏 8 行 22pt 在 3 米外读不动，而待办看不见就等于不存在**。
  - 生日与纪念日页已删除（v0.2 有）——那类内容由右栏倒数日承担。
— 以下为 v0.7 恢复版 —
- **右侧栏 30%，三块面板自上而下：倒数日、明天、本周还剩**：主条目垂直居中，目标名 3.4vmin + 天数 **5.6vmin** + "天后" 2.6vmin，每 5 秒轮换、点一下即换；7 天内转警示色，到当天大字变"今天"。**下方的小圆点与"其余倒数日"列表已删**——它们让右栏看起来像第二个功能区；倒数日总数改为一行小字附在底部。
  - **字号天花板**：内容区任何数字不得超过 `--t-day`（6.0vmin 顶栏日期档），全页唯一更大的是 `--t-clock`（6.8vmin 时钟）。倒数日天数 5.6vmin 在此约束内。口径必须引用 CSS 令牌名而非 pt——上一版写"72pt 档"而实际是 6.0vmin≈49pt，**规范脱离实现令牌，违规就会看起来合规**。
  - 原"今天在场"点阵、"明天"盒、"本周还剩"计数已全部移除。
- **管理入口是右栏底部的一条细行**「管理 ⚙」：无边框、无圆角，只留一道顶部分隔线，字号 2.1vmin、靠右对齐。它曾是占满列宽的 9vmin 圆角大框，既太大又像个漂浮胶囊。曾经靠 `:hover` 才显形的浮动齿轮也已废除——**挂墙触屏没有 hover**，依赖悬停显形的控件在这块屏上等于不存在。
- **底部是一行换屏提示**（普通文字，非胶囊）：`自动换屏 · 2/4 · 今天 → 本周 → 本月 → 待办 · 每 20 秒 · 当前「本周」· 触摸后重新计时`。
- 空态：巨大`今天没有安排`（64pt）+ 一句轻文案。**空态必须好看**——它是家庭屏最常见的状态。

### 3.2 DETAIL 详情覆盖层

居中卡，宽 ≤ 560pt。顶部 6pt 成员色条 → 标题 26pt → 元信息行（成员徽章、日期时间、`↻ 每周三`、`🔔 提前15分`、`📌`）→ 备注块 → 操作行 `编辑` / `复制到此日` / `删除`。重复日程的三个操作各自再弹 §3.5 的三选一。底部一行小字显示"上次由 爸爸 修改 · 3 分钟前"，这条是多人环境的信任基础。

### 3.3 EDITOR 编辑抽屉（底部上滑，最高 480pt）

字段顺序 = 使用频率顺序，这是"3 步记完一件事"的关键：

1. **标题**（自动聚焦，键盘直接弹）
2. **成员**（色块 chips，默认选中上次用的成员）
3. **日期**（默认选中日）｜**时间**（默认下一个半小时刻度）｜`全天` `📌置顶` 开关
4. 折叠区（默认收起）：**重复 → 结束日期** → 提醒 → 备注。「结束日期」只在选了重复时有意义：**留空 = 一直循环，填了 = 该日之后不再出现**（落到 `repeat.until`）。原先的「结束时间」字段已移除，因此日程时长暂不能在界面上录入（见 README v0.16 待确认项）

保存按钮常驻右下，未输标题时置灰。键盘遮挡由 `visualViewport` 监听整体上移。抽屉内若检测到该条被别处改动，顶部出现黄条（§3.6）。

### 3.4 SHEET 管理页（**整屏页面，不是弹窗**，v0.3 改）

v0.2 把它做成"浮在壁挂背景上的覆盖层"。实际推演下来这个折中没意义：挂墙屏进管理模式时，背景那点日历根本不值得保留，反而遮罩+圆角让人误以为"这是个临时浮层，随便点点会关掉"。**改成占满视口的独立页面**，顶栏固定、无遮罩、无圆角、有明确的"✕ 回到壁挂"，视觉上就是一层界面。

- **顶栏**：左「管理」标题，右 `✕ 回到壁挂`（v0.10 起从左上移到右上）；**不放任何说明性提示文字**（旧的"整屏页面 · 操作实时写入服务器 · 静止 60 秒自动回壁挂"已删——它是给开发者看的，不是给家人看的）。
- **一级 tab**：`日历` `待办` `倒数日` `成员` `外观与主题` `提醒与声音` `壁挂与夜间盘` `备份` `关于`。
- 日历 tab 主体 = 月网格 + 右侧当日列表（原覆盖层版的网格规格不变，只是终于有整屏高度可用，1700+ 字符的月视图不再挤压）。
- 面板内所有操作**实时写服务端**（不攒"提交"），因为多人环境下"改完要按保存"会制造不一致窗口。
- 静止 60 秒自动回壁挂；有未保存输入（编辑抽屉打开）时不回落。

### 3.10 待办（`kind='todo'`）

- **壁挂轮播"待办"页**（v0.4 起占整页，不再是右栏小盒）：未完成，按 `sortOrder`→创建时间，每页 6 张大卡。每行 = **6.4vmin 大圆圈**（走近抬手即点）+ 标题 3.6vmin + 成员徽章。点圆圈 → 划线 + 200ms 后淡出，并写 `doneAt`；**不做确认弹窗**（打勾是高频低风险动作）。
- 完成错了怎么办：管理面板"待办"tab 里有"最近完成（14 天内）"，可撤销完成。壁挂端不提供撤销，避免老人小孩看着一堆按钮发懵。
- 三硬规矩（详见 `02` §3.3）：永不自动过期、永不变红催办、只能打勾消失不能顺手删除。
- 新建：`+` 抽屉顶部有类型段控件 `日程 / 待办 / 倒数日`，选"待办"后时间、结束、重复字段整体收起，只剩 标题 · 成员 · 提醒（可选"当天提醒"）· 备注。**类型必须是一级选择而不是藏在折叠区**——藏起来的结果是所有人都会把待办记成"全天日程"，然后待办功能死于无人使用。
- 第 7 条起在待办页折叠为"还有 N 条未完成"，完整清单在管理页。理由很直接：**右栏 8 行 22pt 列表在 3 米外读不动，而待办看不见就等于不存在**；整页既放得下 6 件正经事，又不至于变成某人的无限清单——这个平衡右栏小盒给不了，所以 v0.4 把它挪了出来。

### 3.11 倒数日（`kind='countdown'`）

- 右栏盒内单条轮播 5 秒；大字数字是主体（目标名 30pt + 数字 88pt 等宽 + "天后" 24pt）。
- 三态：`>7 天` 常规色 / `≤7 天` 强调色 / `=0` 文案改"就是今天"并加一枚徽标。
- 带 `yearly` 的目标日过后自动滚到下一年（§5 展开引擎之外的独立计算，见 `02` §5 末段）；不带 yearly 的过期后转"已过 N 天"灰态，等人工处理。
- 生日、结婚纪念日、"距高考 100 天"、"距回老家 23 天"都是它。这类"没有具体时间但全家都在等"的日子，硬塞进日历会污染月视图（它不是某一天的事件），做成待办又必然被勾掉——**所以它是第三个类型，而不是前两者的变体**。

### 3.5 RECUR_ASK 三选一

小卡居中，文案与语义严格照 `02` §4.1。三选按钮：`仅此事件`（主按钮）/ `此事件及以后` / `整个系列`。选"整个系列"且改动涉及起始日时，追加一行橙色说明"原有的 4 个例外日期会一起清掉"。

### 3.6 同步与冲突反馈

| 事件 | 表现 |
|---|---|
| 写请求发出 | 界面立即更新（乐观），顶栏状态点转 300ms 后回绿 |
| 别处改了当前屏可见内容 | 该卡片轻微高亮 1.2s（`outline` 闪一次），不打断操作；若正被编辑则只在抽屉顶部出黄条"这条刚被 X 改过" |
| 409 冲突 | CONFLICT 小卡：左边"我的版本"、右边"服务器上的版本"，三个出口（覆盖 / 放弃 / 看详情） |
| 写失败（断网） | 卡片右上角出现灰色"待同步"角标，顶栏状态点变橙；恢复后自动补发并消失 |
| 正在补发 | 状态点橙→绿之间显示 0.6s 的"↻ 同步中 N 条" |

原则：**同步过程默认静默可见（一个点），异常时才占用注意力。** 家庭软件最忌把技术状态做成弹窗。

### 3.7 SETTINGS 关键项

`提醒与声音`（**含"试听"按钮**——静音键是 iOS 唯一绕不过的坑）、`本机角色`（"作为壁挂主机发声"开关 + 当前主机显示）、`夜间盘时段`、`轮播间隔`、`常亮检查`（自动锁定 / 引导式访问两步引导）、`成员管理`、`备份`（导出/导入，以及"上次成功同步时间"）。

### 3.8 防误触（把管理塞进壁挂屏的必要代价）

- KIOSK 态**只响应"点卡片""点倒数日换一条""点齿轮"三种**，不做滑动手势（滑动改日期、长按快捷删除在挂墙屏上必然误触，全部禁用）。
- 双击不放大（`touch-action: manipulation`），配合 iPad 引导式访问锁死在本页。
- 覆盖层内所有"删除"都是两步（列表项 → 详情 → 删除 → 三选一/确认），没有左滑即删。
- 危险区（清空、导入、归档成员）需输入家庭 PIN。
- **60 秒静止自动回落 KIOSK**；EDITOR 例外（不自动关，避免丢输入），但若 EDITOR 静止 5 分钟且标题为空则自动关。
- 小孩场景兜底：真正防不住的是"人手中拿着的 iPad"，靠引导式访问 + 家长侧密码，不靠 UI。

### 3.9 顶栏状态点（一个元素承担全部同步语义）

`●` 绿=已同步；`●` 绿+微缩时钟=同步中；`●` 橙=有 N 条待同步；`●` 灰 + 灰条"离线只读 · 数据截至 12:03" = 服务端不可达。KIOSK 态下这个点放在时钟左侧，直径 12pt，只有异常时才升级为文字提示。

### 3.12 测试入口的位置（v0.5）

壁挂端**不放任何测试按钮**。提醒到达、别端改动、写冲突 409、服务器断联、静止超时这五个用例全部收进 管理 → 关于 → "自检用例"，正式版连同该分组一起删除；键盘 R / ← → / Esc 保留给开发调试。理由：一块常年挂墙、可能被小孩拍来拍去的屏，顶部那条虚线胶囊本身就是误触源，而且它让原型看起来像半成品。

### 3.13 新建入口的位置（v0.7 定稿）

**入口在哪**：管理页 → 日历 tab → 选中日列表的**右下方**「＋ 新增日程」；成员 tab「＋ 新增成员」（名字 / 首字 / 8 色板，已被占用的色不可选 / 全家公共日历开关），带编辑与归档（归档≠移除，历史日程仍显示归属）；待办 tab 右上「＋ 新增待办」；倒数日 tab 右上「＋ 新增倒数日」。三处按钮都带自己的类型，点下去直接是对应表单，不需要再选类型。**管理页标题区不放新增按钮**——那里放一个全局"＋"会让三种类型的入口混成一个，且标题区是导航区不是操作区。

**弹出形态**：**居中浮窗**（88vmin 宽、内边距 3.2vmin、圆角带阴影），浮在当前界面之上。v0.6 及之前是从屏幕底部升起的抽屉，铺满整宽、把背后内容整块推走。v0.8 又修了一处实现缺陷：浮窗内的 `.ph/.pb` 样式此前只写在 `.panel` 作用域下，而浮窗是 `.drawer`，等于**内边距从未生效**——表现就是文字贴边框、取消按钮是一角小字。教训：**样式作用域要与组件实际容器对齐**，共用类名不等于共用样式。

**层级规则**（§3.14）：管理页是一个**层**，不是一次性页面。在管理页里点日程、点新增、开关冲突提示，管理页都留在身后；只有点标题区的「✕ 回到壁挂」或 60 秒无操作才回壁挂。之前实现把 `layer` 一个变量同时当"当前浮层"和"背景是谁"用，结果管理页里一点日程就露出壁挂——已拆成 `S.base`（背景：kiosk/sheet）+ `S.layer`（当前浮层）。

### 3.14 为什么壁挂端不放新建入口（v0.6 起，仍成立）

挂墙屏是"读"的设备。留一个 9vmin 的 `+` 在它上面，两件事会同时发生：路过时误触的概率不低；而误触弹出的键盘会挡住内容，正在看屏的人什么都看不见，另一个人还没法取消——因为那是他不在跟前的设备。**输入这件事天然属于管理页**（走近、明确进入、有返回按钮、60 秒不操作自动收起），所以新增、编辑、删除全部在管理页内完成，壁挂端只负责显示与打勾。

空态文案也一并改掉：原来写"点右下 + 记一件事"，现在指"点右上「⚙ 管理」记一件事"，避免把用户往一个不存在的按钮上引。

### 3.15 壁挂"看板日"状态（v0.11）

**问题**：壁挂的周页/月页要点某一格才能看那天的清单，但顶栏那行日期是**时钟区**，永远显示今天；页面大标题也还写着"今天"。表现就是"内容已经是 13 号的了，屏上到处都说这是 7 号"。

**做法**（`S.sel !== s.today` 即为看板日状态，不引入额外开关）：

| 元素 | 今天 | 看板日 |
|---|---|---|
| 顶栏日期 + 时钟 | 原样 | **原样不动**——它是"现在几点"，不是"你在看哪天" |
| 内容区大标题 | `今天` | `10月13日 周二`（只换第 1 页；本周/本月本就按这天定位） |
| 提示条 `.lookbar` | 不出现 | `正在看 10月13日 周二 · 不是今天` + `本周 / 本月也按这天定位 · 3 分钟后自动回到今天` |
| 网格里那格 | — | `.mcell.sel` / `.wkcol.sel` 用警示色描边，与"今天"的强调色**分开两种语义** |
| 出口 | — | 提示条上「回到今天」，或等 `dayBack`（默认 180 秒，可在壁挂 tab 换 1/3/10 分） |

三条判断值得记下来：

1. **不改顶栏、只加提示条**。顶栏是时钟，把它改成被点的那天，等于让这块屏失去"现在"这个锚点，反而更难懂。
2. **轮播绝不能因为看板日而停住**。壁挂上没有任何翻页控件（点、方向键都不在），停下就等于把人困在这一页，只能等自动回落——所以三页继续轮播，只是都以这天定位。这是本轮先做成"停留即停轮播"、被自检逼出来才改掉的。
3. **必须自动返回**。谁都可能路过顺手点一下就走；没有 `dayBack` 兜底，这块公共屏就会长期停在某个陌生人关心的日子里。

管理页同一状态用同一套语言：工具条的月标题追加 `· 选中 10月13日`，右侧面板标题写日期，右上角按钮在非今天时从「今天」变成「回到今天」。

### 3.16 管理页的两种手势（v0.11）

壁挂端仍然一个手势都不给（§3.8）。这两种只在管理页装配，且**任何浮层打开时立即失效**——看不见地在改数据是最坏的一类交互。

**跨日拖动改日期**：月/周视图格子里的日程块可以按住拖到另一格，抬手即改日期，语义 = "仅此事件"（§3.5、`docs/02` §4.2）。右侧清单不做拖拽：清单要能上下滚，给它 `touch-action:none` 就会连带吃掉滚动。**轻点不算拖**——位移 8px 以内一律当点击，抬手照旧打开详情。反馈四件套：浮影跟手（`.dragghost`）、来源格变虚（`.drag-src`）、目标格绿框（`.dropover`）、完成后提示条带「撤销」。拖回原格什么都不做。

**待办左右滑**：行左滑露出「删除」、右滑露出「完成」，松手未过半自动弹回。**滑动本身不执行任何操作**，必须再点一下露出的按钮——一条左滑就能删数据的代价是"全家少一件待办"，误触成本太高。露出后行体会描一道红边（删除）或绿边（完成），让"现在是张开状态"这件事可见。删除仍可撤销 6 秒。竖向优先给列表滚动。

**为什么用 Pointer Events 而不是 HTML5 拖放**：`draggable`/`dragstart`/`dataTransfer` 在 iOS Safari 的触摸路径上基本不可用，而这台设备只有触摸。自检里直接钉住了这一条。对手势的真正的系统前提是 **iOS 13 起才支持 Pointer Events**（iPad Air 3 能装到的 iPadOS 远高于此，但要写在这里：万一以后换成更老的设备或某个国产 webview，这两个手势会整体失效，而不是退化成别的操作）。

## 4. 视觉规格

### 4.1 主题令牌（四套色值，一套结构）

组件**只准引用 `var(--c-*)`**，出现写死的十六进制即视为 bug。切换 = 给 `<body>` 换 `data-theme` 属性，无重排、无刷新、无重新登录。

| 令牌 | `ink` 墨蓝 | `night` 夜灰 | `paper` 纸白 | **`wood` 暖木（默认）** |
|---|---|---|---|---|
| `--c-bg` | `#0e1116` | `#000205` | `#f4f5f7` | `#f3ece1` |
| `--c-card` | `#171c24` | `#0c1016` | `#ffffff` | `#fbf6ec` |
| `--c-card2` | `#1d242e` | `#141a22` | `#eef1f5` | `#efe6d6` |
| `--c-line` | `#232a34` | `#1b222b` | `#e3e6ea` | `#ddd0ba` |
| `--c-ink` | `#f2f5f9` | `#e6ebf2` | `#12161c` | `#2b2318` |
| `--c-ink2` | `#9aa7b5` | `#7f8b99` | `#5a6572` | `#7a6a55` |
| `--c-accent` | `#6aa5ff` | `#5b9cff` | `#2f6fdd` | `#a9722e` |
| 成员色档 | 亮档 | 亮档降 10% 饱和 | 深档 | 深档偏暖 |

选型：`night` 给卧室（纯黑无光污染）；`paper` 给厨房/白天强光/长辈看；`wood` 给客厅当装饰面。主题存服务端 `meta.theme`，**全家共享一个值**——这块屏是公共物件，不该每台设备各切各的。

深色主题用**边框分层、不用阴影**（阴影在深色上无意义）；浅色主题允许一层极浅阴影，但仍以边框为主。

### 4.2 通用规格

**基础色（默认 ink）**：底 `#0e1116` → 卡 `#171c24` → 悬停/输入 `#1d242e` → 线 `#232a34`；文字 主 `#f2f5f9` / 次 `#9aa7b5` / 三级 `#5d6875`；强调 `#6aa5ff`（交互色，与成员 blue 同族但不用于成员徽章）、警示 `#ffb454`、危险 `#ff7a6e`、成功 `#4ed08f`。

**字号阶梯以 CSS 令牌为准**：`--t-clock` 6.8vmin（时钟，全页最大）> `--t-day` 6.0vmin（顶栏日期，**内容区天花板**）> `--t-time` 3.8vmin > `--t-title` 3.2vmin > `--t-h2` 3.0vmin > `--t-item` 2.2vmin（3 米可读下限，不可再降）> `--t-meta` 1.7vmin（只许用于管理页角标，**不得出现在壁挂内容区**）。

**字体**：`-apple-system, "PingFang SC", system-ui`，零网络字体；数字一律 `font-variant-numeric: tabular-nums`（否则时钟每秒抖动）。

**点击可达性约束**：浮层基类若设了 `pointer-events:none`，其激活态（`.on`）**必须**把 `pointer-events:auto` 打开，且属性名必须是 `pointer-events`——写成 `pointer:` 会被浏览器静默丢弃，表现为"整块浮层点击穿透、点了没反应"，而事件委托写得再对也救不回来。样式表内出现的属性名需在已核对基线内（自检 H 段拦）。

**样式作用域约束**：`.ph / .pb / .x` 这类跨容器复用的骨架类**必须全局定义**，禁止只挂在某个具体容器作用域下——换一个容器（如管理页的 `.sheet`）复用时就会静默无样式，表现为"改了 DOM 顺序但视觉位置没变"。自检里有针对这一点的样式解析守卫。

**交互可见性约束**：挂在墙上的设备没有 hover 态，常用入口必须常驻、足尺寸、边界明确。

**点击实现约束**：全应用只允许**一个** document 级 click 委托监听，按 `data-*` 属性派发；禁止渲染后逐节点重绑 `onclick`——漏绑一次的后果就是"按钮点了没反应"，而这种缺陷在代码评审里几乎看不出来。自检必须**派发事件**验证交互路径，不接受"按钮存在"这类弱断言。

**手势实现约束（v0.11）**：pointer 监听全部集中在 `src/gestures.js`，界面层只负责在 DOM 上挂 `data-drag` / `data-swipe` / `data-day`。上面那条"一个 click 委托"仍然成立，唯一的额外 click 监听是手势层在**捕获阶段**吞掉拖动/滑动抬手后浏览器必发的那一次 click——不吞的话拖完日期会顺手弹出详情浮层。它必须满足两点：只吞一次、且新的一次按下立刻清掉这个标记（否则"左滑露出删除"后紧接着那下快点会被自己吃掉）。
例外属性 `data-drag` / `data-dragday` / `data-swipe` 在 `static.mjs` 里登记为"手势属性"，同时**反向断言它们真的被 gestures.js 读取**——属性名改一个字母就会静默失灵，只登记不校验等于没校验。

**触摸滚动约束**：可拖元素要 `touch-action:none`，否则浏览器把移动当成页面滚动、JS 收不到完整的 pointermove 序列；但**列表行只能用 `touch-action:pan-y`**（横向交给手势、纵向留给滚动），并且竖向位移大于横向时必须主动放弃这次手势——不然清单就滚不动了。

**手势安全约束**：破坏性操作永不由单次手势完成（滑动只露按钮、执行要再点一下）；任何会改数据的手势必须给可撤销提示；浮层打开、以及非管理页状态下，手势一律不认。

**Esc 语义**：只收起最上层浮层；浮层都不在时按 Esc 无动作。退出管理页必须点右上角的「✕ 回到壁挂」或等 60 秒自动回落——不做"Esc 一路退出"，挂墙屏常被当成"随手按一下就该回去"的设备，误按会让人觉得数据丢了。

**形状**：卡片圆角 14pt、按钮 10pt、chips 胶囊。

**动效**：整屏管理页切换 180ms、抽屉升起 240ms、详情淡入 180ms、提醒横幅 260ms 落 + 60s 停留、卡片高亮闪一次 1.2s、待办打勾划线 200ms + 淡出。尊重 `prefers-reduced-motion`。

**图标**：内联 SVG 或 Unicode，24pt 描边 1.8，不上色。

## 5. 文案

面向家庭，说人话：`记一件事` 而非"新建日程"；`今天没有安排` 而非"暂无数据"。时间不写 ISO：`今天下午 3:00`、`后天 上午9:30`、`每周三`。错误必须给动作：`连不上家里的服务器，检查一下它是否开着` 而非 `请求失败`。涉及 iOS 限制处显式说明，不假装问题不存在（静音键、后台冻结、锁屏不响）。
